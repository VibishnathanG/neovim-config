🚀 HOW TO USE THIS PACKAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: UNDERSTAND (5 minutes)
  ├─ Read: INSTALL_README.md
  └─ Or: bash QUICK_START.sh (to display)

STEP 2: INSTALL (20-30 minutes)
  ├─ chmod +x nvim_complete_setup.sh
  ├─ sudo bash nvim_complete_setup.sh
  ├─ Watch colored output (✓, ✗, !)
  └─ Wait for completion

STEP 3: VERIFY (2 minutes)
  ├─ source ~/.bashrc
  ├─ bash verify-setup.sh
  └─ Check for ✓ marks

STEP 4: COMPLETE FIRST-TIME SETUP (5 minutes)
  ├─ nv (open Neovim)
  ├─ :Lazy sync (install plugins, wait 2-3 min)
  ├─ :Mason (review LSPs installed)
  ├─ :LspInfo (verify LSPs)
  └─ :q (close Neovim)

STEP 5: LEARN (30 minutes to 1 hour)
  ├─ Print/save: QUICK_START.sh
  ├─ Read thoroughly: SETUP_GUIDE.md
  └─ Try keybindings: Open a Python file and test LSP

STEP 6: CUSTOMIZE (As needed)
  ├─ Edit: ~/.config/nvim/lua/keymaps.lua
  ├─ Add plugins: Update ~/.config/nvim/lua/plugins/
  ├─ Sync: :Lazy sync
  └─ Learn more: SETUP_GUIDE.md section "Customization"
